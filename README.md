# 🍽️ Foodies Paradise – Local Food Discovery App

**Foodies Paradise** is a community-driven web application built with **React + TypeScript** that allows users to share and discover authentic local food experiences based on **specific dishes, eateries, localities, and cuisines**.

Unlike rating-heavy platforms, this app focuses on **real food experiences** and **dish-level discovery**, helping users find genuinely good local food recommended by people, not algorithms.

---

👉 **https://localdelicay.netlify.app/**

---

## 🚀 Features

- Add and browse local food experiences
- Search food by **dish name, eatery, locality, or cuisine**
- Global state management using **React Context API**
- Optimized search and filtering using **custom hooks**
- Proper handling of **loading, error, and empty states**
- Clean, minimal, and responsive UI
- Component-level testing with **Vitest** and **React Testing Library**
- Production-ready build and deployment

---

## 🛠️ Tech Stack

- **React**
- **TypeScript**
- **Vite**
- **React Context API**
- **Custom Hooks**
- **Vitest**
- **React Testing Library**
- **CSS (no heavy UI frameworks)**

## 🧠 Key Concepts & Learnings

This project was built as a hands-on learning journey to master **React + TypeScript** using real-world practices:

- Clean component architecture and **separation of concerns**
- Strong domain modeling using **TypeScript types**
- **Derived state vs stored state**
- State lifting and **unidirectional data flow**
- Global state management with **Context API**
- Performance optimization using `useMemo` and `useCallback`
- Reusable business logic via **custom hooks**
- Handling async states: **loading, error, and empty UI**
- Real-world debugging of React, TypeScript, and tooling issues
- Writing meaningful, behavior-driven UI tests
- Preparing a project for **production deployment**
